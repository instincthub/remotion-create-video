# InstinctHub Color System

When applying colors to this project, use the following brand color system. All color values, names, and usage rules below are the source of truth.

---

## Brand Core (Primary)

| Name          | Hex       | Usage                                             |
| ------------- | --------- | ------------------------------------------------- |
| **Dark Cyra** | `#00838F` | Primary buttons, links, highlights, active states |

Dark Cyra MUST remain the dominant brand color across all UI.

## Usage Rules

### Buttons
- **Primary** → `#00838F` background + `#FFFFFF` text
- **Secondary** → `#FFFFFF` background + `#00838F` border + `#00838F` text
- **Danger** → `#EA5F5E` background + `#FFFFFF` text

### Backgrounds
- Main → `#FFFFFF`
- Alternate section → `#F4F3FE`
- Footer → `#206D62` or `#2C333A`

### Text Hierarchy
- H1 / H2 → `#314A52`
- Body → `#2C333A`
- Small text / labels → `#69779B`

### Consistency Rules
1. Dark Cyra (`#00838F`) must remain the dominant brand color.
2. Accent colors must not overpower primary CTAs.
3. Use Magnolia (`#F4F3FE`) to reduce visual fatigue in long dashboards.
4. Max 3 accent colors per screen.

---

Apply these colors whenever styling components, creating themes, or defining color variables in this project. Use the exact hex values listed above.
