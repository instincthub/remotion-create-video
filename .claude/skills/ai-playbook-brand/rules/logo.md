# AI Playbook — Logo System

Source of truth: `docs/01 — Logo`

---

## The Mark

A composite symbol of five interlocking elements:

| Element | Description | Reference |
|---------|-------------|-----------|
| **Vertical bar** | Clean upright stroke on left | Playbook spine, flag pole |
| **D-arc** | Semi-circular arc forming right half | Stage, arena enclosure |
| **Play triangle** | Solid filled triangle inside arc | Live sessions, video, forward motion |
| **Dot** | Small circle outside arc at mid-height | Precision, system node, record button |
| **Two legs** | Short downward strokes below vertical bar | Grounding, flag/bracket completion |

Together: a play button inside a structured framework. Practical, directional, built.

---

## The Wordmark

- **"AI"** — Nunito 700, Brand Charcoal `#2B3A35` on light backgrounds
- **"Playbook"** — Nunito 700, Brand Teal `#1A7A6E`
- Single baseline, single space between words
- Color contrast separates words — no divider
- Mark always sits left of wordmark with consistent spacing

## Logo Variants

### Primary — Light Backgrounds
Use on White or Paper backgrounds.

| Element | Color |
|---------|-------|
| Mark | Charcoal `#2B3A35` |
| "AI" | Charcoal `#2B3A35` |
| "Playbook" | Teal `#1A7A6E` |

### Primary — Dark Backgrounds
Use on Brand Dark `#0F1A17` or other dark surfaces.

| Element | Color |
|---------|-------|
| Mark | White `#FFFFFF` |
| "AI" | White `#FFFFFF` |
| "Playbook" | Teal `#1A7A6E` |

### Teal Background
Use on Brand Teal or Teal Dark backgrounds. All elements white.

### Monochrome White
All-white. For dark backgrounds where teal not available (embroidery, single-color print, dark overlays).

### Monochrome Black
All-black. For light backgrounds in single-color print, stamps, embossing.

---

## Mark-Only Usage

Allowed only in these contexts:
- Social media profile images
- App icons and favicons
- Video watermarks
- Badge and certificate corner marks
- Contexts where brand name is already established nearby

Never use mark alone as primary identification where viewer doesn't know the brand.

---

## Clearspace

Minimum clearspace = height of the mark on all four sides. No element, text, image, or edge within this zone.

At standard horizontal lockup (560px wide): ~48px each side.

---

## Minimum Sizes

| Format | Minimum |
|--------|---------|
| Horizontal lockup (mark + wordmark) | 180px digital / 45mm print |
| Mark only | 24px digital / 8mm print |
| Favicon | 16px |

---

## Logo on Photography

- Ensure sufficient contrast between logo and background
- White monochrome on dark photography
- Dark monochrome or primary on light photography
- Never on busy/high-texture regions
- Add semi-transparent scrim if contrast insufficient

## Misuse — Never Do

1. Recolor any part outside the approved palette
2. Stretch, compress, or distort
3. Add drop shadows, outer glows, gradients, or outlines
4. Place on insufficient-contrast background
5. Rotate any part
6. Rearrange mark and wordmark positions
7. Use wordmark alone without mark (except approved editorial contexts)
8. Use a different typeface for the wordmark
9. Recreate the mark by hand — always use supplied SVG or PNG
10. Animate the logo without explicit approval
11. Attach text, taglines, or other elements to the lockup
