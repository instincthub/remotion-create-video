# AI Playbook — Brand Voice

Source of truth: `docs/AI Playbook - Brand Voice Document`

---

## Core Tone Attributes

| Attribute | Definition |
|-----------|-----------|
| **Clear** | Every sentence earns its place. Precision, not simplicity. Complex things made legible. |
| **Direct** | Lead with the answer, then explain. No excessive hedging or burying the point. |
| **Practical** | Every piece ends with something the reader can do. Applied skills, not interesting ideas. |
| **Grounded** | Real examples, real numbers, real African context. No abstract claims or vague futures. |
| **Honest** | Truth about what AI can and cannot do. Call out hype. Flag limitations. |

**Brand personality:** A senior practitioner who has built things with AI — the clearest explainer in the room. A mentor, not a lecturer. NOT a hype account, motivational speaker, or tech evangelist.

## Vocabulary Blacklist

### Hype Words — Never Use

| Avoid | Use Instead |
|-------|-------------|
| Revolutionary | Specific benefit or outcome |
| Game-changing | Measurable improvement |
| Groundbreaking | Describe what is actually new |
| Disruptive | Specific market change |
| Unlock your potential | Specific skill or capability |
| Transform your business | Specific operational improvement |
| The future of X | What is actually happening now |
| Next-level | Better / more effective / faster |
| Supercharge | Accelerate / improve / increase |
| Leverage (as verb) | Use / apply |
| Synergy | Remove entirely |

### Hedging — Remove

"It is worth noting," "One might argue," "In many ways," "As we all know," "To be honest," "Basically," "Kind of / sort of," "Very / really / quite," "Simply / just / easily"

### Corporate Speak — Avoid

Circle back, Move the needle, Best-in-class, Cutting-edge, State-of-the-art, End-to-end solution, Holistic approach, Deep dive (as noun), Thought leader (self-referential), Value-add, Low-hanging fruit

## Writing Mechanics

**Sentences:** 15-20 words max. One idea per sentence. Active voice default. Vary length for rhythm.

**Paragraphs:** 1-3 sentences for social/newsletter. Up to 5 for blog. Start with the point, not context.

**Headlines:** Lead with specific benefit or tension. Numbers where genuine. Under 50 characters for newsletter subjects.

**Lists:** Numbered for sequences, bullets for non-sequential. Max 7 items. Parallel grammatical structure.

**Formatting:**
- No emojis in formal content (newsletters, blogs, proposals, curriculum)
- Emojis acceptable only in WhatsApp/Discord community
- Bold for key terms and critical info only
- Italics for titles, terms on first use, mild emphasis
- No ALL CAPS — ever
- Sentence case for all headings
- Spell out 1-9; numerals for 10+
- Always numerals for percentages, prices, measurements

**Technical terms** (RAG, LLM, Fine-tuning, Embedding, Vector database, Token, Inference, MLOps, Agent, Hallucination): Define on first use for non-technical audiences.

## Channel Register

| Channel | Register | Style |
|---------|----------|-------|
| Newsletter | Warm, mentor-to-peer | First-person, conversational but structured |
| LinkedIn | Professional, insight-forward | Carousels punchy; text posts personal and direct |
| YouTube | Conversational, teaching-mode | Spoken, step-by-step, explicit transitions, built-in recaps |
| Podcast | Exploratory, dialogue-driven | Relaxed, questions encouraged, tangents allowed if serving listener |
| WhatsApp | Informal, community-first | Short messages, plain language, voice-note friendly |
| Discord | Technical, peer-to-peer | Direct, helpful, no unnecessary politeness |
| Blog/SEO | Structured, thorough, searchable | Headers essential, definitions included, cold-traffic optimized |
| X/Twitter | Sharp, compressed, quotable | One insight per thread, no padding |
| Enterprise | Authoritative, outcome-focused | Third-person, data-driven, structured, no buzzwords |

## What AI Playbook Never Does

- Overpromises outcomes
- Presents AI as replacement for human judgment
- Uses fear as motivation ("you'll be left behind")
- Performs false urgency (countdown timers, fake scarcity)
- Publishes unverified claims
- Uses emojis in formal content
- Uses ALL CAPS
- Uses passive voice to avoid accountability

## Pre-Publish Checklist

- [ ] Leads with the point, not context?
- [ ] Every sentence earning its place?
- [ ] Hedging phrases and fillers removed?
- [ ] At least one specific, actionable takeaway?
- [ ] Technical terms defined on first use (if non-technical audience)?
- [ ] Sounds like practitioner, not marketer?
- [ ] Respects reader's intelligence and time?
- [ ] No hype words, corporate buzzwords, or false urgency?
- [ ] Tone calibrated for specific channel?
- [ ] AI limitations addressed honestly if claiming capabilities?
- [ ] African context referenced naturally if relevant?
- [ ] No ALL CAPS, excessive bold, or decorative formatting?
- [ ] No emojis in formal content?
