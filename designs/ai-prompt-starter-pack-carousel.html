1
Professional
Email Drafter
WRITING

For clear, professional emails quickly — especially difficult conversations, follow-ups, or requests.

Weak prompt

Write me an email about the project delay.

Strong prompt

You are a senior project manager. Write a 150-word email to a client informing them the website launch is delayed by 2 weeks due to API integration issues. Tone: direct but reassuring. Include what happened, what we are doing, and the new go-live date of March 28.

Reusable structure
Role + Task + Word limit + Recipient + Situation + Tone + Required elements
→
2
Report
Section Writer
WRITING

For drafting a section of a formal report, proposal, or business document.

Weak prompt

Write about AI adoption in Nigerian banks.

Strong prompt

Write a 300-word executive summary for a consulting report titled "AI Readiness in Nigerian Financial Services." Audience: C-suite at tier-1 banks. Formal, third-person. Include 2 key findings, 1 risk consideration, and 1 recommended action. Base on industry trends 2023 to 2025.

Reusable structure
Document type + Section name + Word count + Audience + Voice + Required inclusions + Scope
→
3
Data
Interpreter
ANALYSIS

For numbers, survey results, or performance data where you need meaning quickly.

Weak prompt

What does this data mean? [pastes numbers]

Strong prompt

I am pasting monthly active user data for a B2B SaaS product. Analyse it as a growth analyst. Identify the 2 most significant trends, 1 anomaly worth investigating, and 1 metric underperforming against SaaS benchmarks. Output as 3 labelled bullet points, plain English, no jargon. [data]

Reusable structure
Context + Your role + Data type + What to find + Output format + Length constraint
→
4
Competitive
Landscape Analyst
ANALYSIS

For structured comparisons of competitors, tools, or options to support a decision.

Weak prompt

Compare Flutterwave and Paystack.

Strong prompt

Compare Flutterwave and Paystack from the perspective of a Lagos-based startup founder choosing a payment gateway for a B2C e-commerce product. Evaluate on 4 criteria: transaction fees, developer experience, geographic coverage, customer support. Format as a markdown table with a one-sentence recommendation at the end.

Reusable structure
Comparison subject + Evaluator perspective + Use case + Criteria list + Output format + Conclusion
→
5
Topic
Explainer
RESEARCH

For understanding a new concept quickly — or explaining it clearly to someone else.

Weak prompt

Explain machine learning.

Strong prompt

Explain retrieval-augmented generation (RAG) to a product manager at a fintech company who has no engineering background. Use one real-world analogy. Avoid all technical jargon. Keep under 200 words. End with one practical example of how it could be used in financial services.

Reusable structure
Concept + Audience background + Constraints + Analogy requirement + Word limit + Practical application
→
6
Literature and
Source Synthesiser
RESEARCH

For multiple sources, articles, or documents where you need a synthesised view fast.

Weak prompt

Summarise these articles for me. [pastes text]

Strong prompt

Below are three excerpts on AI regulation in Africa. Synthesise them into a 200-word briefing note. Identify 2 points all sources agree on, 1 point of disagreement, and 1 gap none address. Write for a policy audience. Plain English. Do not cite sources by name. [source texts]

Reusable structure
Source type + Synthesis task + Agreements + Disagreements + Gaps + Audience + Style + Length
→
7
Meeting Notes
Condenser
SUMMARISATION

For raw meeting notes, transcripts, or long documents where you need the key outputs fast.

Weak prompt

Summarise this meeting transcript.

Strong prompt

Below is a transcript from a 1-hour product strategy meeting. Extract (1) decisions made, (2) open questions unresolved, (3) action items with owner and deadline if mentioned. Output as three clearly labelled sections. One line per action item. Flag any ambiguous decision with [CLARIFY]. [transcript]

Reusable structure
Input type + Extraction targets + Output sections + Format rules + Special flags
→
8
Long Document
Distiller
SUMMARISATION

For a lengthy report, policy document, or proposal you need to process in under 5 minutes.

Weak prompt

Give me a summary of this PDF.

Strong prompt

This is a 40-page government policy document on digital infrastructure investment. I am a communications director. Give me a 3-sentence executive summary, the 5 most important policy changes, and 2 implications specifically for private sector tech companies. Plain English. Under 300 words total.

Reusable structure
Document type + Your role + Output components + Relevance filter + Style + Word limit
→
9
Options
Evaluator
DECISION SUPPORT

When choosing between two or more approaches, tools, vendors, or strategies.

Weak prompt

Should I use Next.js or Django for my project?

Strong prompt

I am building an AI-powered learning platform needing SSR, a REST API, real-time features, and fast deployment. My team has strong Python skills but limited JS. Evaluate Next.js vs Django + HTMX vs Django + React. Score each 1–10 on team fit, feature coverage, deployment simplicity. Recommend one with a one-paragraph justification.

Reusable structure
Project context + Constraints + Team capability + Options list + Evaluation criteria + Recommendation format
→
10
Risk and
Objection Mapper
DECISION SUPPORT

Stress-test an idea, proposal, or plan before presenting it to stakeholders.

Weak prompt

What are the risks of my business idea?

Strong prompt

I am pitching a B2B AI training programme to enterprise clients in Lagos. $500 per seat, 6 weeks, targeting HR and L&D. Act as a sceptical procurement director at a tier-1 Nigerian bank. Give me the 5 most likely objections you would raise. For each, provide a one-sentence counter-argument I could use.

Reusable structure
Idea or proposal context + Sceptic role + Objection quantity + Objection + counter-argument pairs
→
★
The 5-Part
Master Structure
LEARN ONCE · APPLY EVERYWHERE
01
ROLE
Define who AI should be.
"You are a senior financial analyst..."
02
TASK
State exactly what you want.
"Write a 3-paragraph executive summary..."
03
CONTEXT
Give the background that matters.
"Audience has no technical background..."
04
CONSTRAINTS
Define the boundaries.
"Under 200 words. Formal tone. No bullets."
05
OUTPUT FORMAT
Specify how the result should look.
"Format as a markdown table with 3 columns."
