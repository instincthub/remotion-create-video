How to Use This Pack

Most AI prompts fail for one reason: they are vague. A vague prompt produces a generic response. A precise prompt — one that defines your role, your audience, your constraints, and your expected output — produces something you can actually use.

This pack gives you 10 prompt frameworks across five professional use cases. Each one shows you a weak prompt, a strong version of the same request, and the underlying structure you can reuse for any task in under 60 seconds.

The 60-second prompt structure

Role — who are you asking AI to be?  Task — what exactly do you want?  Context — what background does it need?  Constraints — word count, tone, format, audience.  Output format — how should the result be structured?

Apply this five-part structure to any task and your prompts will produce usable outputs the first time, not the fifth.

WRITING Framework Category
01
Writing
Professional Email Drafter

Use when you need to write a clear, professional email quickly — especially for difficult conversations, follow-ups, or requests.

Weak prompt

Write me an email about the project delay.

Strong prompt

You are a senior project manager. Write a 150-word email to a client informing them that the website launch is delayed by 2 weeks due to unexpected API integration issues. Tone: direct but reassuring. Include: what happened, what we are doing about it, and the new go-live date of March 28.

Reusable structure
Role + Task + Word limit + Recipient + Situation + Tone + Required elements
Example output aim

A client email that gets sent without editing — not one that needs three rounds of rewrites.

02
Writing
Report Section Writer

Use when you need to draft a section of a formal report, proposal, or business document.

Weak prompt

Write about AI adoption in Nigerian banks.

Strong prompt

Write a 300-word executive summary for a consulting report titled "AI Readiness in Nigerian Financial Services." Audience: C-suite executives at tier-1 banks. Formal, third-person language. Include: 2 key findings, 1 risk consideration, and 1 recommended action. Base on general industry trends from 2023 to 2025.

Reusable structure
Document type + Section name + Word count + Audience + Voice + Required inclusions + Scope
Example output aim

A section that drops directly into a client deliverable with minimal editing.

ANALYSIS Framework Category
03
Analysis
Data Interpreter

Use when you have numbers, survey results, or performance data and need to extract meaning quickly.

Weak prompt

What does this data mean? [pastes numbers]

Strong prompt

I am pasting monthly active user data for a B2B SaaS product. Analyse it as a growth analyst. Identify: the 2 most significant trends, 1 anomaly worth investigating, and 1 metric underperforming against typical SaaS benchmarks. Output in 3 labelled bullet points, plain English, no jargon. [data]

Reusable structure
Context + Your role + Data type + What to find + Output format + Length constraint
Example output aim

Three bullet points you can paste directly into a stakeholder update.

04
Analysis
Competitive Landscape Analyst

Use when you need a structured comparison of competitors, tools, or options to support a decision.

Weak prompt

Compare Flutterwave and Paystack.

Strong prompt

Compare Flutterwave and Paystack from the perspective of a Lagos-based startup founder choosing a payment gateway for a B2C e-commerce product. Evaluate across 4 criteria: transaction fees, developer experience, geographic coverage, and customer support. Format as a markdown table with a one-sentence recommendation at the end.

Reusable structure
Comparison subject + Evaluator perspective + Use case + Criteria list + Output format + Conclusion requirement
Example output aim

A table you can share in a team Slack or paste into a decision document.

RESEARCH Framework Category
05
Research
Topic Explainer

Use when you need to understand a new concept quickly — or explain it clearly to someone else.

Weak prompt

Explain machine learning.

Strong prompt

Explain retrieval-augmented generation (RAG) to a product manager at a fintech company who has no engineering background. Use one real-world analogy, avoid all technical jargon, keep the explanation under 200 words. End with one practical example of how it could be used in financial services.

Reusable structure
Concept + Audience background + Constraints + Analogy requirement + Word limit + Practical application ask
Example output aim

An explanation your non-technical colleague forwards to their team.

06
Research
Literature and Source Synthesiser

Use when you have multiple sources, articles, or documents and need a synthesised view quickly.

Weak prompt

Summarise these articles for me. [pastes text]

Strong prompt

Below are three excerpts on AI regulation in Africa. Synthesise them into a 200-word briefing note. Identify: 2 points all sources agree on, 1 point of disagreement, and 1 gap none of them address. Write for a policy audience. Plain English. Do not cite sources by name. [source texts]

Reusable structure
Source type + Synthesis task + Agreements + Disagreements + Gaps + Audience + Style + Length
Example output aim

A briefing note that takes 2 minutes to read and replaces 30 minutes of reading.

SUMMARISATION Framework Category
07
Summarisation
Meeting Notes Condenser

Use when you have raw meeting notes, a transcript, or a long document and need the key outputs fast.

Weak prompt

Summarise this meeting transcript.

Strong prompt

Below is a transcript from a 1-hour product strategy meeting. Extract: (1) decisions made, (2) open questions unresolved, (3) action items with owner and deadline if mentioned. Output as three clearly labelled sections. Keep each action item to one line. Flag any ambiguous decision with [CLARIFY]. [transcript]

Reusable structure
Input type + Extraction targets + Output sections + Format rules + Special flags
Example output aim

Action items distributed in Slack within 10 minutes of the meeting ending.

08
Summarisation
Long Document Distiller

Use when you have a lengthy report, policy document, or proposal you need to process in under 5 minutes.

Weak prompt

Give me a summary of this PDF.

Strong prompt

This is a 40-page government policy document on digital infrastructure investment. I am a communications director. Give me: a 3-sentence executive summary, the 5 most important policy changes, and 2 implications specifically relevant to private sector technology companies. Plain English. Total output: under 300 words.

Reusable structure
Document type + Your role + Output components + Relevance filter + Style + Word limit
Example output aim

A 300-word brief you can read in 90 seconds before a board meeting.

DECISION SUPPORT Framework Category
09
Decision Support
Options Evaluator

Use when you are choosing between two or more approaches, tools, vendors, or strategies.

Weak prompt

Should I use Next.js or Django for my project?

Strong prompt

I am building an AI-powered learning platform needing: server-side rendering, a REST API, real-time features, and fast deployment. My team has strong Python skills but limited JavaScript experience. Evaluate Next.js vs Django + HTMX vs Django + React. Score each 1–10 on: team fit, feature coverage, and deployment simplicity. Recommend one with a one-paragraph justification.

Reusable structure
Project context + Constraints + Team capability + Options list + Evaluation criteria + Recommendation format
Example output aim

A clear recommendation you can defend in a technical review.

10
Decision Support
Risk and Objection Mapper

Use when you need to stress-test an idea, proposal, or plan before presenting it to stakeholders.

Weak prompt

What are the risks of my business idea?

Strong prompt

I am pitching a B2B AI training programme to enterprise clients in Lagos. The programme costs $500 per seat, runs for 6 weeks, targets HR and L&D departments. Act as a sceptical procurement director at a tier-1 Nigerian bank. Give me the 5 most likely objections you would raise. For each objection, provide a one-sentence counter-argument I could use.

Reusable structure
Idea or proposal context + Sceptic role + Objection quantity + Format: objection + counter-argument pairs
Example output aim

Five objections you have already thought through before walking into the room.

The Master Prompt Structure

Every framework in this pack is built from the same five-part structure. Learn it once. Apply it everywhere.

01
ROLE

Define who AI should be.

"You are a senior financial analyst..."  /  "Act as a Lagos-based UX researcher..."

This single line determines the vocabulary, framing, and depth of the response.

02
TASK

State exactly what you want.

"Write a 3-paragraph executive summary..."  /  "List the 5 key objections..."

Be specific. Vague tasks produce vague outputs.

03
CONTEXT

Give the background that matters.

"This is for a client presentation on Tuesday."  /  "The audience has no technical background."

Context eliminates assumptions. Assumptions produce irrelevant output.

04
CONSTRAINTS

Define the boundaries.

"Under 200 words. Formal tone. No bullet points."  /  "Include 2 real examples."

Constraints are not limitations — they are the specification. They save editing time.

05
OUTPUT FORMAT

Specify how the result should look.

"Format as a markdown table."  /  "Three labelled sections."  /  "One sentence per point."

If you do not specify the format, AI will choose one — and it may not be what you need.

What to do next

Pick one task you have been putting off this week. Apply the five-part structure above to write a prompt for it right now. Time yourself. You should be done in under 60 seconds.
