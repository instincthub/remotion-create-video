# 02 — Colour

> Colour is one of the most immediate signals of the AI Playbook brand. The palette is deliberately small: two primary brand colours, two neutral backgrounds, and a supporting set for UI, alerts, and data. Restraint in colour use is a feature, not a limitation.
> 

---

## 2.1 Primary brand colours

### Brand Teal — #1A7A6E

The primary action and identity colour. Used for “Playbook” in the wordmark, interactive elements, calls to action, links, data highlights, and all teal background variants.

| Property | Value |
| --- | --- |
| Hex | #1A7A6E |
| RGB | 26, 122, 110 |
| HSL | 175°, 65%, 29% |
| Pantone (nearest) | 3278 C |
| CMYK (approx) | 79, 0, 10, 52 |

**Usage rules:**

- Use for “Playbook” wordmark at all times
- Use for interactive elements: buttons, links, active states
- Use for data callouts and key statistics
- Use as a background only with white or near-white text on top
- Minimum contrast ratio against white: 4.8:1 — passes WCAG AA for large text

### Brand Charcoal — #2B3A35

The primary text and mark colour. Used for “AI” in the wordmark, the mark on light backgrounds, body text, headings, and all dark-on-light applications.

| Property | Value |
| --- | --- |
| Hex | #2B3A35 |
| RGB | 43, 58, 53 |
| HSL | 162°, 15%, 20% |
| CMYK (approx) | 26, 0, 9, 77 |

**Usage rules:**

- Use for all body text on light backgrounds
- Use for the “AI” wordmark and mark on light backgrounds
- Never use on dark backgrounds — use white instead
- Minimum contrast against white: 9.8:1 — passes WCAG AAA

## 2.2 Background colours

### Brand Dark — #0F1A17

The primary dark background. Deep teal-black. Used for dark-mode hero sections, dark logo variants, video thumbnails, and slide backgrounds.

| Hex | #0F1A17 |
| --- | --- |
| RGB | 15, 26, 23 |

**Usage rules:**

- Use as the background for the dark logo variant
- Use for dark-mode content blocks and hero sections
- Pair with white body text (#FFFFFF) and teal accents (#1A7A6E)
- Never use charcoal text on this background

### Brand Paper — #F4F2ED

Warm off-white. The preferred light background for course pages, document headers, and any context where pure white feels too stark.

| Hex | #F4F2ED |
| --- | --- |
| RGB | 244, 242, 237 |

**Usage rules:**

- Use as an alternative light background where warmth is appropriate
- Use for email body backgrounds and printed materials
- Pair with Brand Charcoal for text

### White — #FFFFFF

Pure white. The default background for the primary logo, course platform UI, and clean document layouts.

## 2.7 Colour combinations — never use these

- Teal on charcoal (contrast too low: approximately 2.6:1)
- Charcoal on dark background (near-invisible)
- Teal text on paper or white below 18px (WCAG AA fail)
- Multiple accent colours in a single layout
- Any colour not in this palette used as a primary brand colour
- Colour gradients involving the brand teal

---

## 2.9 Accessibility

All foreground/background colour pairs used for text must meet WCAG 2.1 Level AA as a minimum:

- Normal text (under 18px): minimum contrast ratio 4.5:1
- Large text (18px+ or 14px bold+): minimum contrast ratio 3:1
- UI components and graphical elements: minimum contrast ratio 3:1

**Verified passing pairs:**

| Foreground | Background | Ratio | Level |
| --- | --- | --- | --- |
| Charcoal #2B3A35 | White #FFFFFF | 9.8:1 | AAA |
| Charcoal #2B3A35 | Paper #F4F2ED | 9.2:1 | AAA |
| White #FFFFFF | Dark #0F1A17 | 17.4:1 | AAA |
| White #FFFFFF | Teal #1A7A6E | 4.8:1 | AA (large text) |
| Teal #1A7A6E | White #FFFFFF | 4.8:1 | AA (large text) |

**Note:** Teal on white passes WCAG AA for large text only (18px+). Do not use teal as the colour for body copy at standard sizes.
