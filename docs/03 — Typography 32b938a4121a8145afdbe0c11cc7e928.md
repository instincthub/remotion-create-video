# 03 — Typography

> Typography is the backbone of the AI Playbook's communication. Three typefaces cover every need: Nunito for identity and display, DM Sans for body and UI, DM Mono for technical and metadata contexts. These three typefaces are used consistently across every channel and asset.
> 

---

## 3.1 Typeface system

### Nunito — Display and identity

Nunito is the AI Playbook's primary display typeface. It is rounded, confident, and readable at large sizes. It is used for the wordmark, main headlines, course titles, slide headers, and any context where the brand voice needs to feel direct and authoritative.

| Property | Value |
| --- | --- |
| Family | Nunito |
| Weights used | 600 (SemiBold), 700 (Bold) |
| Google Fonts | [fonts.google.com/specimen/Nunito](http://fonts.google.com/specimen/Nunito) |
| Import | `@import url('https://fonts.googleapis.com/css2?family=Nunito:wght@600;700&display=swap')` |

**When to use:**

- Page titles and main headlines
- Course and module titles
- Slide deck headings
- YouTube thumbnail text
- Certificate names and titles
- Pull quotes and callouts

**When not to use:**

- Body paragraphs (use DM Sans)
- Long-form instructional text
- Interface labels below 14px

### DM Sans — Body and UI

DM Sans is the workhorse typeface. Clean, neutral, and highly legible at all sizes. Used for all body copy, course descriptions, newsletter text, UI labels, and anywhere extended reading occurs.

| Property | Value |
| --- | --- |
| Family | DM Sans |
| Weights used | 300 (Light), 400 (Regular), 500 (Medium) |
| Google Fonts | [fonts.google.com/specimen/DM+Sans](http://fonts.google.com/specimen/DM+Sans) |
| Import | `@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500&display=swap')` |

**When to use:**

- All body text and paragraphs
- Course module descriptions
- Newsletter body copy
- UI buttons, labels, navigation
- Form fields and inputs
- Captions and footnotes (weight 300)

**When not to use:**

- Headlines above 32px (use Nunito)
- Code snippets (use DM Mono)

### DM Mono — Technical and metadata

DM Mono is used exclusively for technical content, metadata, labels, timestamps, tags, and any context where a monospace rhythm adds clarity.

| Property | Value |
| --- | --- |
| Family | DM Mono |
| Weights used | 400 (Regular), 500 (Medium) |
| Google Fonts | [fonts.google.com/specimen/DM+Mono](http://fonts.google.com/specimen/DM+Mono) |
| Import | `@import url('https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&display=swap')` |

**When to use:**

- Code blocks and inline code
- Section labels and category tags
- Timestamps and week numbers (e.g. WK 01, MONTH 1)
- Metadata rows in tables
- Prompt examples and AI output
- Caption text on diagrams

## 3.5 Spacing and measure

- **Optimal line length (measure):** 60–75 characters per line for body text. Wider than 80 characters reduces readability.
- **Paragraph spacing:** Equal to 1× the line height (i.e., if body is 16px / 1.7 = 27px line height, use 27px paragraph gap).
- **Heading-to-body gap:** 12px below a heading before the first paragraph. 32px above a heading when following body text.

---

## 3.6 Emphasis rules

- **Bold** (Nunito 700 or DM Sans 500): Use for key terms on first introduction, action items, and critical instructions. Not for decoration.
- *Italic* (DM Sans 400 italic): Use for titles of courses, publications, and tools. Use sparingly.
- `Monospace` (DM Mono): Use for all code, AI prompts, command-line instructions, and model names.
- ALL CAPS: Never used for body text. Acceptable only for short metadata labels in DM Mono with letter spacing (e.g. WK 01, MONTH 3).
- Underline: Reserved for hyperlinks only. Never used for decorative emphasis.

## 3.8 Typographic do/don’t

**Do:**

- Use sentence case for all headings
- Maintain consistent type scale across a layout
- Use DM Mono for all AI prompts and outputs shown in examples
- Respect the line-height values — compressed line heights damage readability
- Use left-alignment for all body text; centred alignment only for short display headlines

**Do not:**

- Mix Nunito and DM Sans in the same heading
- Set body text below 14px in any digital context
- Use font weights not in the approved weight set
- Use synthetic bold (browser-applied) — always use a loaded weight
- Use all caps for body text or headings (only for short DM Mono labels)
- Use more than two typefaces in a single layout
